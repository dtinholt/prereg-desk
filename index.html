The Pre-Registration Desk

Write the study down as numbers before you run it. Freeze it and the page gives you a hash to post somewhere public. If the plan has to change, add a dated addendum that chains to the original. When the result comes in, drop the file back here to see each hypothesis marked against the rule you froze.

Import a PREREG markdown

Paste a registration written in the house format, with numbered ## sections and the hypotheses under a heading such as ## 4. Hypotheses, as a table or as bold-labelled bullets. The reader is best effort: it shows what it found before anything touches the form.

1 · The question
2 · Design and sample
3 · Measures
4 · Hypotheses, as numbers
5 · Kill conditions

Each condition names the hypotheses it voids. Write all or a list of ids such as H1, H3. On the Verify tab you tick the ones that fired.

6 · Analysis and reporting
Freezing hashes the plan with the current time inside it and saves a JSON and a markdown copy.
